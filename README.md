# Hushlands

Calm, hyper-real 3D slider (2.5D plane). Unity 6.3 LTS, HDRP, Windows.

- Canon: `docs/game-bible.md` · Process: `docs/playbook.md` · Decisions: `docs/decisions.md`
- Setup: open in Unity 6.3, then menu **Hushlands → Setup → Run Project Bootstrap**.
- Static checks: `python3 tools/validate_project.py`
